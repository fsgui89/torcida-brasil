# Torcida Brasil

Projeto de e-commerce desenvolvido como atividade prática do curso, usando **HTML, CSS e JavaScript puro**.

## Sobre o projeto

A **Torcida Brasil** é uma loja virtual educacional para torcedores brasileiros. O projeto simula uma experiência real de e-commerce com catálogo de produtos, filtros, busca, carrinho, checkout e página de sucesso.

## Funcionalidades

- Catálogo dinâmico usando array de produtos em JavaScript
- Busca por nome
- Filtros por categoria, público e marca
- Ordenação por destaque, menor preço, maior preço e nome
- Página de detalhes do produto
- Carrinho com adicionar, remover e alterar quantidade
- Cálculo de subtotal, desconto, frete e total
- Persistência do carrinho com LocalStorage
- Checkout simulado com Pix, cartão ou débito
- Página de confirmação de pedido
- Layout responsivo
- Botão para voltar ao topo

## Observação importante

Este site foi desenvolvido exclusivamente para fins educacionais, como prática de HTML, CSS e JavaScript.  
As marcas, nomes e imagens citadas pertencem aos seus respectivos proprietários.  
O projeto não possui fins comerciais.
